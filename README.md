# Eletricista: Controle & Lucro

Crie um aplicativo de gestão financeira profissional para um eletricista, moderno, responsivo e pensado principalmente para uso no celular.

LOGOMARCA

Usar obrigatoriamente esta logo oficial:

https://i.postimg.cc/x1pj5JCs/Design-sem-nome.png

Não redesenhar, não alterar cores, não trocar textos e não recriar a logo.

A logo deve aparecer:

Bem GRANDE e centralizada na tela de login.

No topo do aplicativo depois que o usuário entrar.

Em relatórios e resumos financeiros.

Sempre com boa resolução e sem ficar pequena ou espremida.



DESIGN DO APLICATIVO

Criar uma interface extremamente moderna inspirada no iOS/iPhone, com aparência de aplicativo premium.

Identidade visual:

Fundo predominantemente PRETO.

Amarelo da logomarca como cor principal de destaque.

Branco para textos principais.

Cinza escuro para cartões secundários.

Botões amarelos com detalhes pretos.

Cards com efeito 3D.

Bordas arredondadas.

Sombras suaves.

Efeito de profundidade.

Pequenos efeitos de vidro/glassmorphism.

Ícones modernos estilo iOS.

Animações suaves ao abrir cards e menus.

Navegação simples e elegante.

Não deixar o aplicativo carregado visualmente.

O sistema deve parecer um aplicativo financeiro premium instalado em um iPhone, e não uma página de site comum.

TELA INICIAL / DASHBOARD

Após o login, mostrar a logo no topo.

Abaixo:

Olá! 👋

Resumo Financeiro

Criar cards modernos mostrando:

💰 Valor recebido

Total de todos os serviços realizados no período.

💸 Gastos

Total de todas as despesas.

📈 Lucro

Calcular automaticamente:

Valor dos Serviços − Gastos = Lucro

O lucro deve aparecer em destaque.

Exemplo:

Receitas
R$ 3.850,00

Gastos
R$ 1.240,00

Lucro
R$ 2.610,00



FILTRO DE PERÍODO

Ao tocar, todos os valores do painel devem ser recalculados automaticamente.

EXPERIÊNCIA MOBILE

Priorizar 100% o uso no celular.

O aplicativo precisa:

Abrir rápido.

Ter botões grandes.

Ter ótima leitura.

Funcionar perfeitamente em iPhone e Android.

Ter aparência de aplicativo e não de site.

Utilizar cards arredondados estilo iOS.

Ter transições suaves.

Ser simples para uma pessoa que não entende de tecnologia utilizar.

Não criar telas desnecessariamente complicadas.

RESULTADO ESPERADO

Quero um aplicativo:

PRETO + AMARELO

com visual:

3D + iOS + iPhone + premium + moderno + profissional

Utilizando a logo oficial grande e destacada.

O aplicativo deve ser simples de operar, mas completo o suficiente para que um eletricista consiga controlar diariamente:

quanto recebeu + quanto gastou + quanto realmente lucrou.

Não criar dados falsos permanentes no aplicativo.

Caso seja necessário mostrar exemplos durante o desenvolvimento, usar apenas dados demonstrativos que possam ser apagados.

O foco principal deve ser:

SERVIÇOS → GASTOS → LUCRO → HISTÓRICO → CONTROLE FINANCEIRO.
